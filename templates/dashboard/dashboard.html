Sobre a NR-1

A NR-1 estabelece diretrizes para o Gerenciamento de Riscos Ocupacionais (GRO) e Programa de Gerenciamento de Riscos (PGR), incluindo riscos psicossociais.

Este sistema oferece uma solução completa e auditável para identificação, avaliação e gestão de riscos psicossociais no trabalho.

{% include 'components/icons/icon.html' with name='shield-check' class='w-5 h-5 text-green-600' %}

Garantia de Anonimato

Todos os dados são processados com k-anonymity, garantindo que nenhum colaborador possa ser identificado.

Os dashboards só exibem dados agregados de grupos com no mínimo 5 respondentes, em conformidade com a LGPD.
